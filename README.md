# 扫雷 · Minesweeper

一个零依赖、单文件的现代版扫雷小游戏。双击 `index.html` 即可在浏览器中直接运行，无需安装任何环境或服务。

## 运行方式

- **本地游玩**：直接双击 `index.html`，用任意现代浏览器（Chrome / Edge / Firefox）打开即可。
- **发布部署**：把这一个文件上传到任意静态空间（GitHub Pages、对象存储、Nginx 静态目录等）即可在线游玩。

## 功能特性

### 玩法

- **首击必安全**：第一次点击的周围 3×3 区域保证没有雷
- **泛洪展开**：点开空白格自动扩散，带波浪式动画
- **快速翻开（Chord）**：双击或中键已翻开的数字格，当旗数与数字匹配时一键翻开周围格子
- **首击公平布雷**：雷在第一次点击后才生成

### 难度

| 难度 | 棋盘 | 雷数 |
|------|------|------|
| 初级 | 9 × 9 | 10 |
| 中级 | 16 × 16 | 40 |
| 高级 | 30 × 16 | 99 |
| 自定义 | 行 5–24 / 列 5–30 | 自定 |

- 每种难度的**最佳成绩**自动保存在本地（localStorage）

### 操作

| 操作 | 说明 |
|------|------|
| 左键 | 翻开格子 |
| 右键 / 长按 | 插旗 / 取消旗 |
| 双击 / 中键 | 对数字格快速翻开 |
| `R` | 重新开始 |
| `Esc` | 关闭结算弹窗 |

- 触屏适配：长按插旗（带震动反馈），并提供专用的**插旗模式**切换按钮

### 界面与音效

- 深色 / 浅色双主题，一键切换并自动记忆
- 经典表情状态按钮（🙂 等待 / 😮 按下 / 😎 胜利 / 💀 失败）
- 爆炸震动特效、胜利彩带庆祝、自动补旗
- Web Audio 合成音效（翻开、插旗、爆炸、胜利），可一键静音
- 格子尺寸随窗口自适应缩放，且缩放不会丢失进行中的棋局

## 技术说明

- **单文件**：HTML + CSS + JavaScript 全部内联在 `index.html` 中，约 30KB
- **零依赖**：无任何框架、库或外部资源，离线可玩
- **音效**：由 Web Audio API 实时合成，无音频文件
- **数据存储**：主题、音效开关、最佳成绩均使用 localStorage
